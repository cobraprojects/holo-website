@holo-js/storage

Different disks. Same file API.

Store files locally, serve public uploads, or use S3-compatible storage through the same API. Your media library builds on these disks with model collections and conversions.

CONFIG CHANGESdefaultDisk: 'local'
SAME APPLICATION CODE 
await Storage.put('avatars/ava.png', file)
const avatar = await Storage.get('avatars/ava.png')
INTERACTIVE ILLUSTRATION

avatar.png → public disk

Storage uses the configured default disk. S3 credentials and disk configuration belong in your environment.

Explore storage →Explore the media library →
@holo-js/db

New database. Same domain.

Start with SQLite, move to PostgreSQL or MySQL. Keep your model calls and portable schema migrations while the configured connection changes.

CONFIG CHANGESdriver: 'sqlite'
SAME MIGRATION 
await schema.createTable('posts', table => {
  table.id()
  table.string('title')
  table.timestamps()
})
INTERACTIVE ILLUSTRATION

Portable schema → configured database

Install the chosen driver and configure its connection. Existing data must be migrated separately; database-specific SQL is not portable.

Explore database →
